# Welcome to the Dreamlab Docs!


Dreamlab is a 2D game engine that helps you build games fast. It features:

- **Built-in Multiplayer:** Every game you create in Dreamlab is multiplayer-ready by default. No server setup or additional plug-ins
- **Web-Based and Collaborative** Dreamlab runs entirely in the browser and you can share your editor session with a link
- **AI Tools** Built-in AI assistant helps you write code
