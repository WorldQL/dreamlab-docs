# Game Jams

Dreamlab is an [open-source](https://github.com/WorldQL/dreamlab-engine) web game engine with Google Docs-style collaboration. Game jam teams can collaborate on code and design levels together in real time. Dreamlab is similar to Godot and Unity, so you can get started quickly.

Check it out:

Two teams in the [Pirate Software Jam](https://itch.io/jam/pirate) are planning to use it for their game. **If you're interested, please [check out the tutorial](./index.md) to learn the basics of the engine in just 15 minutes.** You can also [join our Discord for support](https://discord.gg/Tbpy3kbuaW).
