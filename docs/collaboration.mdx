# Collaboration

Dreamlab is an [open-source](https://github.com/WorldQL/dreamlab-engine) web game engine with Google Docs-style
collaboration. Game jam teams can collaborate on code and design levels together in real time.

<video src="/img/collab.mp4" style={{ maxWidth: "100%" }} autoPlay muted playsInline controls></video>

This requires no setup and is automatically available on all Dreamlab projects. It uses the same networking features that we use to power multiplayer!
